# デザイン原則(カラー・タイポグラフィ・スペーシング)

> これらの値は `frontend/src/theme/index.ts` に実装し、常に同期させること。

---

## 1. カラーパレット

### プライマリ / セカンダリ

| トークン | 値 | 用途 |
|---------|----|------|
| primary.main | `#1B5E43`(深緑) | 主要アクション、ヘッダー。碁盤・盤面を連想させる落ち着いた緑。表ヘッダーの白文字背景を兼ねるため変更しない(白文字コントラスト7.7:1) |
| primary.dark | `#0F3D2A` | ホバー・アクティブ |
| primary.light | `#E8F2ED` | 選択状態の背景。共有ページのヘッダー帯背景(`02_component_design.md`) |
| secondary.main | `#8A6530`(榧色・かやいろ) | 補助的アクセント用に温存(現状の実装では未使用)。白文字使用時はAA(5.27:1)を満たす濃さに設定済み。小さな本文テキストの文字色には使わない(背景に対しAA large相当のため) |

### セマンティックカラー

| トークン | 値 | 用途 |
|---------|----|------|
| success.main | `#2E7D32` | 勝ち、確定済み、成功トースト |
| error.main | `#C62828` | 負け、削除、エラー |
| warning.main | `#B34F00` | 未入力警告、制約緩和警告。共有ページの申告不一致テキスト(`color="warning.main"`)は本文色として直接使われるため、和紙背景(`background.paper`)に対しAA(4.5:1)を満たす濃さに調整した(旧`#EF6C00`は3.0:1でAA未達。SHR-AC-019で機械検査) |
| info.main | `#1565C0` | 情報通知 |

### ニュートラル(2026-08 デザイン刷新: 墨・和紙を基調に暖色寄りへ変更)

| トークン | 値 | 用途 |
|---------|----|------|
| text.primary | `#231F1B`(墨) | 本文。和紙(background.default)に対し14.8:1 |
| text.secondary | `#6B655C`(墨鼠) | 補足テキスト。和紙に対し5.2:1 |
| background.default | `#F7F3EC`(生成・きぬ) | ページ背景。和紙を連想させる温白 |
| background.paper | `#FFFDF9`(生成紙) | カード・表。純白ではなく紙の白 |
| divider | `#DDD4C4`(墨線) | 罫線。木目・畳表に近い暖色の罫線 |

以前の値(`#1A1A1A` / `#5F6368` / `#FAFAF7` / `#FFFFFF` / `#E0E0DC`)は冷色寄りで、
デザインコンセプト(和・落ち着いた品)を表現していなかったため置き換えた(`.claude/07_plans/03_design_system_brushup.md`)。
`rank.gold/silver/bronze` の背景色は新しいニュートラルに対しても AA を満たすため変更していない。

### 順位カラー(共有ページ・管理画面の順位カード)

| トークン | 値 | 用途 |
|---------|----|------|
| rank.gold | `#F5C542`(背景は `#FBE8A6`) | 1位カードの強調色 |
| rank.silver | `#9AA0A6`(背景は `#E4E5E7`) | 2位カードの強調色 |
| rank.bronze | `#C97A3D`(背景は `#EFD3BC`) | 3位カードの強調色 |

### カラー使用ルール

1. 勝敗の表現は**色だけに頼らない**(○/●記号・文字を併記。色覚多様性対応)
2. テキストと背景のコントラスト比は WCAG AA(4.5:1)以上
3. 上記トークン以外の色を追加する場合は本ドキュメントに追記してから使う

## 2. タイポグラフィ

フォント: `"Noto Sans JP", "Hiragino Sans", "Yu Gothic", sans-serif`(数字は `font-feature-settings: "tnum"` で等幅表示 — 順位表の桁揃え用)

| variant | サイズ / 太さ | 用途 |
|---------|-------------|------|
| h1 | 2rem / 700 | ページタイトル(大会名) |
| h2 | 1.5rem / 700 | セクション見出し |
| h3 | 1.25rem / 600 | カード見出し |
| body1 | 1rem / 400 | 本文 |
| body2 | 0.875rem / 400 | 補足 |
| caption | 0.75rem / 400 | メタ情報(更新時刻等) |

- **共有ページ(スマホ)の本文は最低16px**(高齢参加者への配慮 + iOS自動ズーム防止)
- 卓番号・順位など「会場で瞬時に読む数字」は h2 相当以上の大きさで表示

---

## 3. スペーシング

- 基準: **8pxグリッド**(`theme.spacing(1)` = 8px)
- 使用可能な値: 4(0.5), 8(1), 16(2), 24(3), 32(4), 48(6), 64(8)
- コンポーネント内部の余白: 16px、カード間: 16px、セクション間: 32px
- タップターゲット: **最小44x44px**(結果入力ボタンは56px以上)

---

## 4. その他トークン

| 項目 | 値 |
|------|----|
| 角丸 | 8px(カード・ボタン共通)。`borderRadius: 2`(theme単位)。例外: 共有ページのヘッダー帯(24px = `borderRadius: 3`)・卓番号タイル(20px、正円に近い丸みのため固定px値)。詳細は `02_component_design.md`「共有ページの意匠」参照。運営者管理画面(`TournamentLayout`)の見出し行への同トークン適用は `07_plans/04_design_system_rollout.md` で計画中 |
| 影 | elevation 0〜2 のみ使用(フラット寄り)。ダイアログのみ8 |
| 罫線 | 1px solid divider |
| ダークモード | MVPでは対応しない(テーマ分岐を書かない) |

## 5. 印刷トークン(`theme.print`)

帳票印刷(S13)専用。A4の物理寸法(mm)と印刷本文サイズ(pt)は8pxグリッドで表現できないため、
`palette.rank` と同じ module augmentation で `theme.print` に独立トークンとして持つ(`04_layout_system.md` §5参照)。

| トークン | 値 | 用途 |
|---------|----|------|
| pageMargin | 10mm | ページの余白。`@page` ではなく `body` の padding として適用する(下記注記参照) |
| cardGap | 4mm | 対局カード間の切り取り余白 |
| bodyFontSize | 10pt | 名簿・対戦結果表の本文 |
| tableFontSize | 9pt | 名簿・対戦結果表のセル |
| cardFontSize | 7pt | 対局カードの本文(A8相当は文字が小さくなるため別トークン) |
| headerBg | #EEEEEE(薄グレー) | 表ヘッダーの地色。緑ベタ塗りはインクを食うためモノクロ運用 |
| writableRowHeight | 14mm | 手書き記入欄を持つ表(対戦結果表)のデータ行の高さ。相手・結果を手書きできる余白を確保する |
| cardWritableRowHeight | 8mm | 団体戦の対局カードの手書き記入行(相手・チーム勝敗・個人勝敗)の高さ |
| opponentColWidth | 10mm | 対戦結果表の各ラウンド「相手」列の幅。相手はNo.(数字)のみのため狭くし、結果列を相対的に広く目立たせる |
| eventDateBlankWidth | 30mm | 帳票ヘッダーの開催日が未設定のとき、手書き用に確保する記入枠(下線)の幅 |

実装は `theme/index.ts`(変更時はこのファイルと同期すること)。
